# Code of conduct

Openergy welcomes contributors with different backgrounds and levels of
experience. Be respectful in issues, reviews, discussions, and other project
spaces. Critique the work with clear evidence and give others room to correct
mistakes.

## Expected behavior

- Use considerate language and discuss technical disagreements in good faith.
- Respect privacy. Do not publish personal information, input recordings,
  clipboard contents, or private messages without permission.
- Keep reports and reviews focused on the project. Accept reasonable requests
  to stop disruptive behavior.

Harassment, threats, discriminatory remarks, sexual harassment, deliberate
intimidation, and repeated personal attacks are not acceptable. Do not misuse
the project's input-sharing features to access or disrupt another person's
computer.

## Reporting and enforcement

Report conduct problems to the repository maintainer. If the report is safe to
share publicly, use an issue and link the relevant public interaction. If it
contains sensitive details, request a private contact channel without posting
those details. The project does not currently list a dedicated confidential
conduct mailbox; do not assume a public issue is private. Security problems
follow [SECURITY.md](SECURITY.md).

Maintainers may edit or remove harmful content, close or lock discussions,
warn participants, or restrict participation. They should apply these measures
consistently, consider context, and avoid disclosing a reporter's private
information. Reports about a maintainer can be raised with another repository
maintainer if one is available; an independent appeal body is not promised.
